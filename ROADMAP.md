# 后续方向 · Roadmap

首版范围与已验证结果见 [README](README.md) 和 [深化审计](docs/EXPANSION-AUDIT.md)。本页列出可讨论的后续工作，不表示已开工或承诺发布日期。

See the README and audit for the first edition's scope and verified results. This page lists possible follow-up work for discussion, not active commitments or promised release dates.

| 方向 · Direction | 完成依据 · Evidence of completion |
| :--- | :--- |
| 学术纠错与补证 / Scholarly corrections | 用原始来源定位问题，记录定义边界、修改理由与双语复核。<br />Locate issues in original sources and record boundaries, reasons for changes, and bilingual review. |
| 独立审读 / Independent review | 取得审读者同意后记录其真实身份、范围与意见；未完成前不作专家背书。<br />With reviewer consent, record actual identity, scope, and findings; make no prior claim of expert endorsement. |
| 使用体验 / Usability | 由具体读者问题驱动，验证键盘、窄屏、公式与搜索流程。<br />Start with specific reader problems and verify keyboard use, narrow screens, formulas, and search. |
| 新词条与案例 / New entries and cases | 先检查重复、来源可用性和教学价值，再完成双语、对照、练习及审校。<br />Check overlap, source access, and teaching value before completing both languages, contrasts, exercises, and review. |

通过 [改进建议](https://github.com/Horace-Maxwell/logic-wiki/issues/new?template=proposal.md)提出范围与验收方法。网站部署不属于当前交付范围。

Use a proposal issue to suggest scope and acceptance criteria. Website deployment is outside the current delivery scope.
