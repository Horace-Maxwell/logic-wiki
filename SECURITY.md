# 安全政策 · Security policy

## 报告漏洞 · Report a vulnerability

请通过 [GitHub 私密漏洞报告](https://github.com/Horace-Maxwell/logic-wiki/security/advisories/new)提交可能涉及脚本注入、依赖、构建流程或数据泄露的问题。该仓库已启用私密报告。不要在公开 Issue 中发布凭据、个人数据或可直接利用的攻击细节。

Report possible script injection, dependency, build-process, or data-exposure vulnerabilities through GitHub's private vulnerability reporting link above. Private reporting is enabled for this repository. Do not post credentials, personal data, or directly exploitable details in public issues.

报告应包含受影响的提交或版本、运行环境、最小复现、预期影响，以及不含敏感数据的示例。只在你有权测试的环境中验证。

Include the affected commit or version, environment, minimal reproduction, expected impact, and a sample without sensitive data. Test only in environments you are authorized to assess.

## 维护范围 · Maintenance scope

安全修复以 `main` 的当前代码为目标；旧快照不设独立维护分支。本项目没有固定响应时限或漏洞赏金计划。维护者会在报告线程中沟通复现、修复与披露安排。

Security fixes target the current code on `main`; older snapshots have no separate maintenance branches. The project has no guaranteed response time or bug bounty program. Maintainers will discuss reproduction, fixes, and disclosure in the report thread.

此仓库发布源码，默认在本地运行；维护者没有部署公共网站。其他人自行托管的实例由其运营者负责。文章中的推理错误或翻译问题请使用[内容纠错模板](https://github.com/Horace-Maxwell/logic-wiki/issues/new/choose)。

This repository publishes source for local use; the maintainer has not deployed a public website. Operators are responsible for their own hosted instances. Use the content-correction template for reasoning or translation errors in articles.
