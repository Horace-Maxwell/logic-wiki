# 许可说明 · Licensing

## 当前状态 · Current status

项目尚未授予覆盖全部原创代码与内容的统一许可证。公开仓库方便阅读与核查；再利用时不要将第三方 Humanizer 的 MIT 许可理解为整个仓库的授权。

The project has not granted a blanket license covering all original code and content. The public repository supports reading and verification; the third-party Humanizer MIT licenses do not license the entire repository.

具体再利用许可可向 [仓库维护者](https://github.com/Horace-Maxwell/logic-wiki/issues/new?template=proposal.md)说明拟使用的文件、用途和分发方式。未获得相应授权的材料不要复制到本项目。有关无许可证仓库的说明见 [Choose a License](https://choosealicense.com/no-permission/)。

For reuse permissions, describe the files, purpose, and distribution method in a request to the repository maintainer. Do not copy material into this project without the relevant permission. Choose a License explains the implications of an unlicensed repository.

## 第三方材料 · Third-party material

随仓库保存的 Humanizer 规则分别适用其原 MIT 许可证。教材、引文、依赖与其他材料保留各自的许可；具体位置见 [NOTICE.md](NOTICE.md) 与来源登记。

The vendored Humanizer rules retain their original MIT licenses. Textbooks, quotations, dependencies, and other materials retain their own terms; see the notices and source register for details.

## 贡献与署名 · Contributions and attribution

提交贡献时说明作者及你有权提供该材料的依据。内容许可尚未统一期间，涉及再利用授权的贡献先通过 Issue 与维护者确认。项目引用格式见 [CITATION.cff](CITATION.cff)；引用仓库时同时记录使用的提交号，文章中的学术论断仍需引用原始来源。

Identify authorship and your basis for providing contributed material. While content licensing remains unspecified, discuss contributions involving reuse permissions with the maintainer in an issue. Use the citation file for this project and record the commit used; scholarly claims in articles still need citations to their original sources.
