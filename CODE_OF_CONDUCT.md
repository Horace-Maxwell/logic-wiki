# 行为准则 · Code of conduct

本准则适用于本仓库的 Issue、PR、评审和其他项目讨论。维护者与贡献者适用同样的要求。

This code applies to issues, pull requests, reviews, and other project discussions. It applies equally to maintainers and contributors.

## 如何讨论 · How to participate

讨论具体论证、证据和修改方案。允许直接指出错误，也允许有依据的分歧。批评他人的结论时，应说明前提、推理或来源出了什么问题，给对方解释与纠正的机会。

Discuss specific arguments, evidence, and proposed changes. Direct criticism and supported disagreement are welcome. When challenging a conclusion, identify the problem with its premises, inference, or sources, and allow room for explanation and correction.

不得进行人身侮辱、歧视、骚扰、威胁或反复针对个人的攻击；不得发布他人的私人信息、冒充他人或伪造来源与审校身份。

Do not insult, discriminate against, harass, threaten, or repeatedly target people. Do not publish private information, impersonate others, or fabricate sources or reviewer identities.

## 处理问题 · Handling problems

普通讨论问题可在相关线程中说明具体言行与希望的处理方式。涉及隐私、威胁或骚扰时，使用 GitHub 针对相关内容或账户提供的举报功能；不要为举报而再次公开私人信息。项目没有另设保密邮箱。

For ordinary discussion problems, identify the conduct and requested resolution in the relevant thread. For privacy violations, threats, or harassment, use GitHub's reporting controls for the content or account; do not repost private information in a report thread. The project has no separate confidential email address.

维护者可根据具体情况要求修改、隐藏或删除违规内容、锁定讨论，或限制参与。善意的学术分歧本身不是违规理由。对处置有异议，可在允许回复的相关线程请求复核；平台层面的处置由 GitHub 负责。

Maintainers may request revisions, hide or remove violating content, lock discussions, or restrict participation as circumstances warrant. Good-faith scholarly disagreement alone is not a violation. You may request reconsideration in the relevant thread where replies are possible; GitHub handles platform-level enforcement.
