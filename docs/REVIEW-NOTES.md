## 本次实际修正

- 排除双语分隔符与条件概率竖线的冲突，避免概率正文被截断。
- 重写小项不当周延的第一案例，使中英文使用同一类别关系；统一两个否定前提的对照。
- 将模态辖域案例改为明确的可能世界/设定情境，避免数学对象的必然属性与随机选择混杂。
- 重写中文句法歧义案例，使用确有不同分组方式的短语；去掉额外的“拥有望远镜”推断。
- 将“同住不是证据”收窄为“仅凭同住不足以证明参与”，保留证据强度差别。
- 区分拒绝无根据主张与声称已经驳倒，避免错误分配举证责任。
- 修正“大家都”与英文 many 的量词差异；在全称量词练习中明确采用人的论域。
- 条件概率不再被写成必然不相等；合取规则中的 A 明确不排除 B。
- 多重检验算例补充“独立且误报率恰为 5%”；十次抽签算例保留不中奖概率。
- 将 converse accident 合并为草率概括的别名，补入独立的可能性到必然性错误词条。
- 为摩尔的自然主义谬误增加专门学术来源，保留其争议性质；选择偏差、前提缺陷与讨论策略另标性质。
- 核对 OPERA 原文短摘，使用作者实际写出的句子；Lumosity 改引 Brill 声明，避免仅以案件目录支撑具体主张。
- 保留重复研究、p 值和模型结论的适用范围，不把未显著改写为已证伪，不把模型分析改写为所有论文的实测普查。
- 去掉词条页首与定义部分的整段重复；保留用于教学的统一章节和必要的否定对照。

构建检查遍历全部生成页面的内部链接与锚点，核对单语言 JSON 导出、练习、公式工具、站点地图和搜索索引。网页未出现的外部来源全文不被自动视为已审读。
