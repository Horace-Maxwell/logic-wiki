# 获取帮助 · Getting help

| 问题 · Need | 入口 · Where to go |
| :--- | :--- |
| 安装、启动、搜索 / Setup, startup, search | [README 快速开始 / Quick start](README.md#quick-start) |
| 学习顺序与词条范围 / Study order and coverage | [内容地图 / Content map](docs/CONTENT-MAP.md) |
| 定义、译文、引文或答案纠错 / Content, translation, citation, or answer corrections | [内容纠错 Issue / Content correction](https://github.com/Horace-Maxwell/logic-wiki/issues/new?template=content-correction.md) |
| 网站故障 / Website bugs | [故障报告 Issue / Bug report](https://github.com/Horace-Maxwell/logic-wiki/issues/new?template=bug-report.md) |
| 建议功能或资料 / Feature or source proposals | [改进建议 Issue / Proposal](https://github.com/Horace-Maxwell/logic-wiki/issues/new?template=proposal.md) |
| 可能的安全漏洞 / Possible vulnerabilities | [安全政策 / Security policy](SECURITY.md) |

提问前请搜索已有 Issue。运行故障请附上操作系统、Node 版本、提交号、执行命令与最小复现。内容问题请给出稳定词条 ID、语言、具体章节与可查来源。粘贴日志前移除令牌、个人路径及其他敏感信息。

Search existing issues first. For runtime failures, include your operating system, Node version, commit, command, and minimal reproduction. For content questions, provide the stable unit ID, language, section, and a checkable source. Remove tokens, personal paths, and other sensitive information from logs.

支持通过公开 Issue 提供，没有固定答复时限。无需把同一问题重复发布到多个模板。

Support is provided through public issues without a guaranteed response time. One issue per problem is sufficient.
